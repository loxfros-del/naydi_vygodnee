# NOVA web

NOVA — жёлто-чёрный PWA для спокойного поиска выгодных товаров. Сервис бесплатный. Введите товар, модель и важные параметры; NOVA автоматически распознает поддерживаемую категорию. Бюджет можно не указывать — тогда NOVA сравнит рынок целиком. Сохранённые поиски остаются только в браузере этого устройства.

Для живого поиска через существующий Search Engine V2 запускайте из корня репозитория:

    python tools/run_nova_web.py

Откройте `http://localhost:8080`. Проверка сервера: `http://localhost:8080/api/health` вернёт `{"status":"ok","service":"nova-web"}`. В браузере можно установить приложение через системное действие «Установить приложение» или «Добавить на главный экран».

Сервер работает только локально и использует кэш в памяти. Он не меняет `bot.db` или другие SQLite-файлы. Для публичного запуска понадобятся отдельные безопасность, авторизация и инфраструктура.

## Telegram Mini App

Обычный браузер остаётся полностью рабочим: поиск идёт через `/api/search` без Telegram-данных.

Внутри Telegram NOVA подключает `Telegram.WebApp`, учитывает безопасные отступы экрана и показывает компактный статус подключения. `initData` передаётся только один раз на `/api/telegram/session` для серверной проверки; он не сохраняется в браузере, не добавляется к ссылкам и не отправляется с запросом поиска. Фронтенд получает только безопасный контекст `{telegram: true, displayName?: string}`.

### Что нужно для реального запуска в боте

1. Разместить `web/` и `tools/run_nova_web.py` за публичным HTTPS-доменом, например `https://nova.example/`.
2. На сервере бота задать `MINI_APP_URL=https://nova.example/` и перезапустить бот. Локальный `http://localhost:8080` намеренно не становится кнопкой в Telegram.
3. В BotFather настроить Main Mini App или Menu Button на тот же HTTPS-адрес — это добавит вход из профиля и нижнего меню бота.

До шага 1 кнопки «Открыть NOVA» в чате нет по дизайну: это защита от неработающего локального адреса. После шага 2 появится клавиатурная кнопка «⚡ Открыть NOVA». Настройка BotFather остаётся ручной: она требует доступа владельца к боту.

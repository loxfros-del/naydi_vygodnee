# Исправление PS4 в выдаче PS5 — 13.09.2026

По последнему требованию владельца Avito выдаёт только проверенные совпадения, а в режиме «Найти выгоднее» — только с доказанной экономией. Указание от 09.09 о заполнении 3/5 карточек непроверенными объявлениями отменено. 3/5 теперь максимум. При отсутствии подходящих предложений результат пустой с одной причиной.

## Причина и исправление

На скриншоте PS4 уже имела статус отличия, но попадала в публичную выдачу через дополнительный список найденных объявлений. Этот путь был предусмотрен прежней политикой. Теперь публичный `discoveredListings` пуст; исходные объявления доступны только владельцу в `adminDiscoveredListings`. Авторизация владельца больше не меняет обычный список рекомендаций.

Проверка идентичности действует до AI и повторяется перед выдачей. Алиасы PS5/ПС5/PlayStation 5 сопоставляются; другое поколение, конфликт названия с параметрами, аксессуары, игры, аренда и пустые коробки исключаются из запроса консоли. Упоминание совместимости с играми PS4 в описании настоящей PS5 само по себе не отклоняет её. Модель, исполнение и дополнительные обязательные характеристики проверяются отдельно.

Источник запрашивается по релевантности: дешёвые посторонние товары больше не получают преимущество сортировки до проверки модели. Это не гарантия качества сторонней поисковой выдачи. Уже полученные подходящие объявления из рыночной выборки могут пройти полноценную проверку кандидата, фотографий и обновление прямой страницы, без нового сбора ради заполнения списка.

Сервер перед сериализацией проверяет безопасную роль, соответствие полному запросу, завершённый анализ, подтверждение состояния по доступным данным, полную цену и свежесть страницы. В режиме `bargain` дополнительно обязательны сопоставимая конфигурация, действующие пороги независимого рынка и подтверждённая экономия. Пороги не снижены. Проверка `stock` остаётся отключённой; исправность устройства не доказывается дистанционно.

Ключи кэша обновлены. UI не восстанавливает отчёты старой политики и не запускает платный повторный поиск автоматически. Видны выбранные фильтры, а при редактировании товара раскрываются дополнительные требования. Примеры сохраняют город и бюджет пользователя. Диагностические карточки отделены от результата покупателя.

Отдельно исправлена обнаруженная тестами Windows-гонка записи в файл блокировки расходов. Денежные лимиты, срок ожидания и журнал резервов сохранены. Подробности и первичный источник Microsoft — в исследовании ниже.

## Проверки

Использован встроенный Python `C:\Users\Пользователь\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe`, из корня проекта.

- `python -B -m unittest discover -s tools -p 'test_avito_*.py'` — **282 теста, OK**, включая 17 проверок расходов и фактический локальный HTTP POST/poll. Лог: `runtime/strict_avito_final_tests.txt`.
- Сценарий со скриншота: PS4 при PS5 → ноль публичных карточек; неправильные кандидаты не отправляются на AI-текст, фото или обновление.
- Положительный сценарий: PS5 с десятью независимыми подходящими аналогами → одна проверенная выгодная карточка, без заполнения до трёх. Числа и ссылки в фикстурах синтетические.
- Отдельно проверены недостаток доказательств рынка, изменение цены/модели при обновлении, сбой обновления, повторное использование полученного рынка и повторная проверка полного запроса перед сериализацией.
- `python -m compileall -q app avito_service tools` — exit 0, без предупреждений.
- Полный `python -m compileall -q -x '(^|[\\/])(\.venv|\.git|\.codex|\.agents|node_modules|\.pytest_cache)([\\/]|$)' .` — exit 0; обход сообщил недоступные `.pytest_cache` и `runtime/qa_deps`. Их содержимое не считается проверенным. Защищённые папки исключены из компиляции.
- Исходный `tools/test_alice_parser.py` — «ВСЕ ТЕСТЫ ПРОЙДЕНЫ УСПЕШНО». Выполнен через `runpy` с настройками в памяти, подменённым HTTP и заблокированным `sqlite3.connect`, по точной схеме из [предыдущего аудита](product_selection_audit_2026-09-13.md). Код парсера не подменялся.

- `node tools/test_avito_card_presentation.js`, `node tools/test_avito_results_presentation.js` — оба прошли после последней правки UI. Выполняются реальные функции JS-рендерера, восстановления задачи и обработки формы в VM с подменой DOM/сети. Проверены PS4 в диагностике, одна выгодная PS5, пустой результат, старая политика, режим `find`, фильтры и сохранённые задачи. Последние регрессии проверяют конкретную `emptyReason`, экранирование HTML и отсутствие повторов.
- `node --check avito_web/app.js` — прошёл.
- Попытка браузерной проверки через CUA: список приложений/браузеров пуст, `getBrowser` вернул `No browser is available`. Визуальная проверка и скриншоты не получены. Пользовательский сервер 8091 не останавливался и не перезапускался; отдельный браузерный тестовый сервер не запускался. HTTP-тесты выше использовали временные локальные серверы и завершили их сами.

# Расширенный поиск Avito и GPT‑4.1 mini

Состояние: **23.09.2026**. Отдельный Avito Review; Telegram, его ключ, оплата и база не изменяются.

## Что включено

Публичный файл [review_profile.json](../avito_service/review_profile.json) выбирает `gpt-4.1-mini` через AI Tunnel, анализ текста до 200 объявлений пакетами по 5, бюджет AI 50 ₽ и потолок Apify $2 на весь поиск. Интерфейс запрашивает до 200 исходных объявлений; 3/5 по-прежнему обозначают максимальное число итоговых карточек. Цена и активность финалистов обновляются отдельно, под это заранее резервируется бюджет.

При расчётном курсе 100 ₽/$ предел отчёта — 250 ₽. Сохраняются общие ограничения журнала Apify: $3 за сутки и $18 за период подписки с 9-го по 8-е по времени Москвы. Если остатка не хватает, фактический сбор будет меньше или остановится. 200 — верхняя граница, а не обещание количества найденных товаров. Не удалять `runtime/avito_spend.json` для обхода лимитов.

Поиск остаётся в Ярославле с самовывозом. PS4, аксессуары, чужие города и неподходящие версии не дополняют выдачу. Малая положительная экономия допускается: от 3 до 9 независимых сопоставимых продавцов — «Дешевле найденных аналогов» с размером выборки, от 10 — «Ниже рынка». История ремонта/деталей может быть неизвестной только с явным предупреждением; разные комплекты, версии и известная/неизвестная история сравниваются отдельно.

## Настройка и запуск в VS Code

Если AI Tunnel и Apify уже настроены, достаточно остановить старый сервер `Ctrl+C`, запустить заново и обновить страницу `Ctrl+F5`. Сервер печатает выбранную модель и лимит сбора, без ключей.

```powershell
cd "C:\Users\Пользователь\Documents\naydi_vygodnee"
& "$env:USERPROFILE\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe" -m avito_service --port 8091
```

Для настройки только текущего терминала используются переменные процесса. Ниже именно шаблон: значения в угловых скобках нужно заменить локально своими ключами; `.env` редактировать не требуется.

```powershell
$env:APIFY_TOKEN = "<ваш токен Apify>"
$env:AVITO_AI_BASE_URL = "https://api.aitunnel.ru/v1"
$env:AVITO_AI_API_KEY = "<ваш ключ AI Tunnel>"
$env:AVITO_AI_MODEL = "gpt-4.1-mini"
```

Адрес интерфейса: `http://127.0.0.1:8091/`. Ключ AI Tunnel предназначен для AI Tunnel; он не становится ключом другого провайдера при замене адреса API.

## Приоритет настроек

1. Переменные текущего процесса имеют приоритет.
2. Для хоста `api.aitunnel.ru` применяются разрешённые несекретные поля `review_profile.json`; они заменяют устаревший выбор модели и бюджетов из локальной конфигурации.
3. Остальные значения берутся из существующей локальной конфигурации и безопасных значений по умолчанию.

Профиль не содержит ключей и не заменяет URL провайдера. Для другого хоста этот профиль не применяется. Команда `$env:AVITO_REVIEW_PROFILE = "off"` отключает чтение JSON-профиля на следующий запуск. Она не удаляет переменные процесса и не отключает ограничения сервера/SpendingGuard. Удалить конкретное переопределение из текущего терминала можно, например, `Remove-Item Env:AVITO_AI_MODEL -ErrorAction SilentlyContinue`.

## Проверка работы и пределы результата

Проверка нового маршрута на сохранённых публичных материалах: три PS5 получили законченный текстовый анализ, PS4 был отклонён, девять фотографий одной PS5 получили законченный анализ. Два ответа со строгой JSON-схемой содержали стоимость 0,39 ₽ и 0,99 ₽, всего **1,38 ₽**. Артефакты: `runtime/avito_gpt_migration_20260923`. Это проверка работы модели на прежних материалах, не подтверждение сегодняшних цен, активности или трёх выгодных предложений.

Офлайн-тест с настоящим кодом Zen-провайдера и подставленным HTTP проверяет 200 исходных записей плюс отдельное обновление 3/5 финалистов. `effective_apify_max_charge_usd` ограничивает отдельный запуск Actor; общий бюджет поиска остаётся $2. Новая модель не создаёт отсутствующие объявления и не заменяет доказательства экономии.

## Альтернативы

`gpt-4.1` и `gemini-2.5-flash` остаются кандидатами для сравнения на одинаковых описаниях и фото. Их преимущество для этого проекта не доказано. Перед переходом проверять существующий ID, поддержку изображений/JSON, число ошибок, время и фактическую стоимость; сохранять те же правила товара, города и сравнения. Обоснование и первичные ссылки: [исследование моделей](avito_yield_model_research_2026-09-13.md), [каталог AI Tunnel](https://aitunnel.ru/docs/models), [поддержка JSON-схем](https://aitunnel.ru/docs/structured-outputs).

По [описанию Zen Actor](https://apify.com/zen-studio/avito-listings-scraper), Free ограничен 100 объявлениями за запуск и 10 запусками всего; больший сбор требует подходящего платного плана. Явная ошибка такого ограничения не запускает новый платный сбор автоматически. Параметры `query`, `location`, `maxResults` и `searchUrl` описаны в [официальной схеме Actor](https://apify.com/zen-studio/avito-listings-scraper/input-schema); увеличение числа записей не является разрешением расширять город.

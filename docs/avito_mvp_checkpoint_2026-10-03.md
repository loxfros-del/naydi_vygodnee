## Что нужно для завершения

Восстановить устойчивое соединение с AITUNNEL и подтвердить его бесплатными проверками на другом сетевом маршруте. Историческую ошибку через доступные Live логи восстановить нельзя; отсутствие строки расходов не является квитанцией на 0 ₽. Не отправлять ещё один пакет без нового разрешения владельца. Финальное обновление цены/активности допустимо лишь после полной безопасной проверки фото. **Финалистов нет**; сохранённая карточка 8125174775 не является рекомендацией.

**Render отложен владельцем**, сервис не развёрнут, внешней ссылки нет. Когда владелец вернётся к этому шагу: вход в Render, подключение репозитория, согласование показанной стоимости экземпляра с диском, настройка секретов через панель, перенос журнала и сверка SHA, внешний HTTP-smoke. Бюджет поиска $8 не считается согласием на подписку хостинга. Blueprint использует `0.5c-512mb` ([официальные планы Render, проверено на предыдущем этапе 03.10.2026](https://render.com/docs/compute-plans)); точная сумма оплаты должна быть показана аккаунтом до создания услуги.

Для аудита использован только [GET списка user runs Apify](https://docs.apify.com/api/v2/actor-runs-get), не запуск Actor. Новые внешние цены товаров не искались и не заявлялись актуальными.

# Ограниченное сравнение моделей Avito

Этот план поддерживается по `.agent/PLANS.md`. Задача ограничена резервом стоимости в `avito_service/ai.py`, уточнением общего текстового промпта и отдельным инструментом сравнения без изменения конфигурации или оплаченных данных.

## Purpose / Big Picture

Владелец сможет сравнить текстовые решения трёх проверенных моделей на одном сохранённом наборе объявлений. Без `--live` команда не читает конфигурацию и не обращается к сети; она проверяет вход и показывает план. С `--live` действует один общий бюджет, расходы без квитанции учитываются как оценка. Это исследовательская диагностика, не выдача рекомендаций клиенту.

## Surprises & Discoveries

Если AITUNNEL не присылает usage, прежний код резервировал весь AI-бюджет для любой модели кроме Qwen. Это делало сравнение с GPT/Gemini неравным даже при небольшой стоимости запроса. Обычные публичные карточки содержат только descriptionExcerpt, поэтому для сравнения необходим полный description из сохранённого normalized JSON.

При первом тесте локальная остановка бюджета оборачивалась reviewer в AI_INVALID_RESPONSE. Для CLI введён отдельный тип ComparisonBudgetExceeded; теперь остановка сохраняет смысл и не запускает повтор. Фотографии с подтверждёнными token counts не должны оцениваться по максимальным 32К токенов на каждый снимок; новые тесты проверяют приоритет этих данных и отсутствие двойного учёта reasoning.

## Decision Log

Ставки резерва за миллион входных/выходных токенов: Qwen40/100, GPT100/400, Gemini250/2000 ₽. Они выше проверенных тарифов и явно помечаются estimated. Неизвестные модели сохраняют консервативный полный резерв; CLI допускает только конечный проверенный список. Источник ставок и ограничений сохранён в docs/avito_yield_model_research_2026-09-13.md.

По уточнению владельца добавлены GPT-5.6 Sol и алиас openai/gpt-5.6-sol со ставками 2300/14000. Production сохраняет повтор HTTP429; только CLI отключает его, чтобы каждый транспортный вызов проходил собственный резерв. Общий лимит ответа production 2400 сохраняется, ограничение CLI применяется одинаково ко всем сравниваемым моделям.

CLI использует существующий текстовый reviewer, без фото и Apify. Бюджет разделяется всеми моделями и объявлениями; перед запросом сумма резервируется, при неоднозначной ошибке резерв не освобождается. Оценка не является гарантированным пределом внешнего биллинга: если реальная квитанция превышает резерв, её сохраняют целиком и следующие вызовы останавливают.

## Context and Orientation

`avito_service/ai.py` строит текстовые payload, вызывает совместимый Chat Completions endpoint и проверяет JSON. `NormalizedListing` и `SearchRequest` определены в `avito_service/models.py`. Сохранённые файлы пилота содержат dataclasses.asdict объявления и соседний request.json. Новая команда `tools/compare_avito_models.py` читает эти файлы; `tools/test_avito_model_costs.py` и `tools/test_compare_avito_models.py` используют только искусственные данные и mocked transport.

## Plan of Work

Выделить `estimate_payload_cost(payload)` из текущей ветки Qwen и добавить проверенные алиасы. В общем текстовом промпте уточнить, что неуказанная модификация необязательна, а чужое поколение недопустимо. Добавить отдельную CLI-команду с ограниченным входным JSON, повторяемым `--model`, `--max-listings`, `--max-cost-rub`, `--live` и JSON-отчётом в новый локальный файл. Офлайн-путь завершается до чтения load_config. Сетевой путь требует HTTPS AITUNNEL, использует общую учётную сумму и не сохраняет ключи или сырые ошибки.

## Concrete Steps

В корне проекта запустить:

    python -X utf8 -m unittest tools.test_avito_model_costs tools.test_compare_avito_models tools.test_avito_ai_transport
    python -X utf8 tools/compare_avito_models.py --help

Сохранённый массив принимает соседний request.json, либо один файл содержит request и listings. Пример офлайн-плана:

    python -X utf8 tools/compare_avito_models.py --input runtime/pilot/candidates-normalized.json --model qwen3.8-flash --model gpt-4.1-mini --max-listings 3 --max-cost-rub 10

Флаг `--live` вводит пользователь, когда намеренно запускает платное сравнение. В текущей задаче он не запускается.

## Validation and Acceptance

Тесты должны доказать, что правильная стоимость не заменяется оценкой, нечисловая/отсутствующая стоимость учитывается консервативно, дополнительные фото увеличивают резерв. Клиент PS5 получает одинаковое правило неуказанных версий в одиночном и пакетном промпте. CLI без --live не вызывает load_config или сеть. При недостаточном общем резерве очередной запрос не выполняется; ошибки не освобождают неопределённые расходы. Итоговый файл содержит только выбранные выводы и агрегаты стоимости, без токенов и полного текста продавца.

## Idempotence and Recovery

Входные данные не меняются. Отчёт создаётся в новый файл; существующие файлы не перезаписываются. Повторный запуск создаёт отдельную сводку. При сбое сети неопределённый резерв остаётся учтённым, следующий запуск не запускается автоматически.

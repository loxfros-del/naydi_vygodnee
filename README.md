# Найди выгоднее — Telegram-бот

Сервис поиска выгодных товаров. Пользователь описывает товар текстом, бот уточняет детали, создаёт заявку. Админ берёт заявку в работу, добавляет варианты, отправляет предпросмотр и полный отчёт после оплаты.

Правила честного сравнения, проверки разных категорий и понятного диалога сохранены в [базе знаний подбора](docs/product_selection_knowledge.md) с семью первичными интернет-источниками. [Аудит от 13.09.2026](docs/product_selection_audit_2026-09-13.md) описывает исправления Telegram и Avito, проверки и оставшиеся ограничения.

Позднейшее уточнение владельца от 13.09.2026 ужесточает выдачу Avito: только проверенные совпадения, а в режиме поиска выгоды — только подтверждённые предложения ниже рынка. Причины ошибки PS5/PS4 и исследование открытых проектов сохранены в [исследовании точного поиска](docs/strict_search_research_2026-09-13.md).

## Стек

- Python 3.11+
- aiogram 3
- SQLite
- python-dotenv
- pydantic

## Структура

```
main.py                  # Точка входа
app/
  config.py              # Настройки из .env
  db.py                  # SQLite: модель заявки, CRUD
  states.py              # FSM-состояния
  keyboards.py           # Клавиатуры
  search_links.py        # Генерация поисковых ссылок
  request_parser.py      # Чистый разбор текста заявки
  product_search.py      # Multi-source автопоиск и ранжирование кандидатов
  report_builder.py      # Предпросмотр и полный отчёт
  handlers/
    user.py              # Обработчики пользователя
    admin.py             # Обработчики админа
```

## Статусы заявки

`NEW` → `SEARCHING` → `PREVIEW_SENT` → `PAID` → `REPORT_SENT` → `CLOSED`

## Установка

```bash
python -m pip install -r requirements.txt
cp .env.example .env
# Заполнить .env: BOT_TOKEN и ADMIN_IDS
python -m compileall .
python tools/test_search.py "Нужен телевизор для PS5 до 45к в Ярославле"
python main.py
```

## Команды бота

- `/start` — начало работы
- `/admin` — панель админа (только для ADMIN_IDS)

## Telegram Mini App

NOVA можно открыть прямо из меню бота. После размещения сайта на публичном HTTPS-адресе задайте переменную окружения `MINI_APP_URL`, например `https://nova.example/`, и перезапустите бота. Бот покажет кнопку «⚡ Открыть NOVA»; без этого адреса обычный Telegram-бот и браузерный NOVA продолжают работать как прежде. Локальный `http://localhost:8080` подходит только для разработки и намеренно не показывается Telegram-клиенту. Для постоянной кнопки в профиле и меню дополнительно настройте Main Mini App или Menu Button в BotFather на тот же URL.

## Как работает

1. Пользователь нажимает «🔍 Найти товар» и описывает что ищет.
2. Бот извлекает: товар, бюджет, город, цель, критерии.
3. Если данных мало — задаёт 2-3 уточняющих вопроса.
4. Пользователь подтверждает заявку.
5. Админ видит заявку через `/admin`, берёт в работу.
6. Админ может проверить заявку через Алису или GigaChat: вставляет ответ ИИ, получает отдельные карточки, выбирает ТОП-1 и проверяет прямые ссылки.
7. Ручное добавление остаётся запасным сценарием: `Название | Цена | Магазин | Ссылка`.
8. Админ открывает «👁 Полный предпросмотр для админа»: в нём видны все товары, цены, магазины, ссылки и риски.
9. Клиент получает только «👀 Клиентский предпросмотр до оплаты» без моделей, цен, магазинов и ссылок.
10. После ручного нажатия «✅ Оплата подтверждена» админ отправляет полный отчёт со ссылками.

## Автопоиск v2

Автопоиск собирает карточки кандидатов, а не выдаёт ссылки как готовые товары.
Он использует независимые источники: DDGS (если установлен), публичную выдачу
Wildberries и site-поиск Ozon, Яндекс Маркета, DNS, М.Видео и Авито. Ошибка
одного источника не останавливает остальные. Если карточек нет, поисковые
ссылки сохраняются только как ручный fallback и видны в «🧪 Debug поиска».

## Отдельный Avito Review

`avito_service/` и `avito_web/` работают отдельно от Telegram, оплаты и базы бота. Запуск: `python -m avito_service --port 8091`, интерфейс — `http://127.0.0.1:8091/`. Для реального поиска нужны локально настроенные `APIFY_TOKEN`, `AVITO_AI_API_KEY`, `AVITO_AI_BASE_URL` и мультимодальная `AVITO_AI_MODEL`. Секреты не вводятся в форму поиска и не добавляются в Git.

Сервис собирает две выборки: рынок без ценовых ограничений клиента и кандидатов в его бюджет. Сначала проверяются описание, совпадение характеристик и полная цена с доплатами; аналоги анализируются независимо от дешёвого списка кандидатов. После сравнения цен проверяются фото финалистов и повторно загружаются их прямые ссылки. Неактивные страницы, неизвестные обязательные характеристики и изменившиеся данные исключаются из клиентских рекомендаций. Поле наличия `stock` не проверяется и не влияет на отбор. Финальное обновление цены и активности страницы принимает данные источника не старше минуты; сохранённая проверка действительна 15 минут, исходное время не подменяется временем чтения кэша.

С 13.09.2026 «Найти выгоднее» (`bargain`) показывает только подходящие проверенные товары с доказанной экономией относительно сопоставимых предложений. «Найти точно» (`find`) показывает проверенные совпадения и без доказанной экономии. Выбранные 3/5 — максимум карточек, а не обязательное число: PS4 не заполняет место PS5, непроверенные и рискованные объявления не дополняют результат. Если подходящих предложений нет, выдаётся пустой результат с причиной. Это правило одинаково для обычного и административного просмотра клиентской выдачи; исходные найденные объявления доступны владельцу отдельно в `adminDiscoveredListings`, служебные рекомендации и предупреждения — в `adminRecommendations` и `adminWarnings`. Публичный `discoveredListings` пуст. Оба режима собирают кандидатов с сортировкой по релевантности; сравнение полной цены выполняется после проверки соответствия.

Рынок считается по независимым идентификаторам продавцов, которые хранятся только в виде хеша. Кандидат и все объявления его продавца исключаются из его сравнения. По подтверждённому уточнению владельца, зафиксированному 23.09.2026, от 3 до 9 других сопоставимых продавцов допускается метка «Дешевле найденных аналогов» с размером небольшой выборки; «Ниже рынка» — от 10. Достаточна любая положительная разница между медианой полных цен и полной ценой кандидата; порог 2 000 ₽ / 5% для Avito отменён. При менее трёх продавцах или неполной проверке карточка не попадает в `bargain`. Ссылки и время наблюдений доступны в карточке. Это цены объявлений, а не совершённых сделок. Маркер текущей политики API — `verified_comparable_savings`; старый отчёт не запускает платный поиск автоматически.

Общий запрос «PS5» допускает версии семейства, включая Slim, когда версия не задана. Явные требования к версии, дисководу, памяти и комплекту остаются обязательными. Для расчёта экономии PS5 Slim сравнивается с такой же Slim, а не с обычной PS5, Digital или Pro другой конфигурации. Текущий запрос владельца: только Ярославль, самовывоз; автоматического расширения города нет. В форме по умолчанию выбраны Ярославль и «Только самовывоз в выбранном городе» (`pickupOnly` в API). Примеры и сброс дополнительных параметров сохраняют город, бюджет и выбранное ограничение самовывоза.

Новые, б/у и восстановленные товары сравниваются отдельно. Для б/у учитываются комплект, ремонт, оригинальность деталей и, для смартфонов, группа состояния аккумулятора. По отдельному разрешению владельца от 23.09.2026 отсутствие сведений о ремонте и оригинальности деталей допускается с заметным предупреждением на карточке (`historyWarnings`), вне свёрнутых деталей. Неизвестная история не считается чистой и сравнивается отдельно от известной; противоречия и дефекты не проходят. Обязательные доплаты и обязательная доставка входят в цену покупки; если они неизвестны, рекомендация запрещена. При включённом самовывозе обязательная доставка исключает предложение, а различия необязательной доставки не разделяют сопоставимые предложения. Фото и текст показывают признаки состояния, но не подтверждают исправность скрытых компонентов: это прямо указано клиенту вместе с вопросами перед покупкой.

Один лимит расходов охватывает рыночный сбор, кандидатов, повторную проверку и AI. По умолчанию отчёт ограничен 50 ₽, AI — 15 ₽, условный расчётный курс — 100 ₽/$; это защитная настройка, а не текущий валютный курс. Оценка Apify использует консервативные Free-ставки, фактическая стоимость записывается отдельно. Первый AI-вызов может стоить дороже оценки, поэтому для абсолютного ограничения нужно также ограничить бюджет ключа у AI-провайдера. В Apify действует `maxTotalChargeUsd` на каждый запуск в пределах общего остатка.

Сопоставимые рыночные снимки сохраняются на 15 минут в игнорируемой папке `runtime/avito_market_cache` (до 64 записей). Контакты и исходные ответы профилей в этот кэш не включаются. Кэш AI не заменяет повторное обновление цены и активности страницы. Файл Dataset можно импортировать только владельцу: он даёт предпросмотр и не имитирует актуальную проверку.

Поиск и импорт выполняются через общую очередь, максимум две активные задачи и 20 новых задач в час на процесс. Повторные клики по активному запросу переиспользуют задачу. 45 секунд — цель интерфейса; сервер работает до 180 секунд, браузер восстанавливает ход и готовый результат по номеру задачи до 15 минут. При перезапуске процесса задачи теряются, рыночный кэш сохраняется.

Панель владельца требует `AVITO_OWNER_TOKEN` — отдельный случайный ключ не короче 32 символов в окружении процесса. Кнопка «Войти» принимает его и хранит только в текущей сессии браузера. `?owner=1` сам по себе не предоставляет доступ. Для внешнего адреса или туннеля задайте также `AVITO_ACCESS_TOKEN` для участников пилота и используйте HTTPS. При публичном bind без ключа сервер не запускается. Это доступ закрытого пилота; индивидуальных аккаунтов и клиентского биллинга здесь пока нет.

По состоянию на 7 сентября 2026 года Starter Apify стоит $19 в месяц и включает $19 на использование. Zen Studio ограничивает Free десятью запусками всего; платный план снимает этот лимит. На Starter 100 полных записей стоят приблизительно $0,60 плюс возможные дополнительные операции, AI оплачивается отдельно. Условия: [Apify](https://apify.com/pricing), [Zen Studio](https://apify.com/zen-studio/avito-listings-scraper/pricing).

### Телеметрия контролируемого Avito live pilot

Телеметрия выключена по умолчанию и не меняет фильтры или лимиты. Для одного ручного пилота запустите новый процесс PowerShell:

```powershell
$env:AVITO_LIVE_PILOT="1"
python -m avito_service --port 8091
```

Каждый вручную созданный поиск сохраняет атомарный trace в `runtime/avito_pilot_traces/<job_id>.json`. В нём нет ключей, Authorization headers, cookies, полных AI prompts и изображений. Неизвестная фактическая стоимость записывается как `null`; консервативная оценка хранится отдельно.

После ручных поисков получить сводку:

```powershell
python tools/summarize_avito_pilot.py
python tools/summarize_avito_pilot.py --json
```

Команда только читает локальные JSON-файлы и не обращается к Apify или AI. Не запускайте цикл платных запросов: сценарии пилота выполняются по одному через web-интерфейс после проверки `maxTotalChargeUsd`, дневного журнала `runtime/avito_spend.json` и AI-бюджета.

Если старый `.venv` создан в пути с кириллицей и его launcher не запускается, не ремонтируйте его поверх существующего. Создайте чистое окружение в коротком ASCII-пути и установите зафиксированный список зависимостей:

```powershell
py -3.12 -m venv C:\venvs\naydi-avito
C:\venvs\naydi-avito\Scripts\python.exe -m pip install -r requirements.txt
C:\venvs\naydi-avito\Scripts\python.exe -m avito_service --port 8091
```

Если `py -3.12` отсутствует, сначала установите Python 3.11+ и повторите команды. Секреты в команды, trace и Git не добавляются.

Порядок первого пилота и критерии результата: [docs/avito_pilot.md](docs/avito_pilot.md).

Пилот 9 сентября: 96 записей, 75 уникальных объявлений, фактический сбор $0,60504. [Результаты и ограничения](docs/avito_pilot_results_2026-09-09.md). По запросу владельца от 9 сентября через `build_service` и инструмент пилота действует потолок Apify $1 на поиск, $3 за сутки и $18 за период подписки с 9-го по 8-е число по времени Москвы. Учёт сохраняется в `runtime/avito_spend.json`; при неизвестной стоимости резерв не освобождается. Ручные запуски в кабинете Apify и другие проекты в этот лимит не входят. Не удаляйте журнал для сброса ограничения.

В админке после запуска откройте «📦 Показать найденные варианты», отметьте
хотя бы один вариант как лучший/нормальный/дешёвый/надёжный, затем отправляйте
предпросмотр и отчёт. Диагностика доступна по кнопке «🧪 Debug поиска» или
командой `/debug_search REQUEST_ID`.

Ручное добавление из чата администратора (запасной сценарий):

```text
/add_result REQUEST_ID | Название | Цена | Магазин | Ссылка | Плюсы | Риски
```

## Сценарий Алисы / GigaChat

1. В карточке заявки нажмите «🟡 Проверить через Алису» и скопируйте промпт; его можно использовать и в GigaChat.
2. Вставьте текст ответа Алисы или GigaChat обратно в бот. Поля «Ссылка», «Прямая ссылка» и «Прямая ссылка на товар» распознаются одинаково.
3. Бот покажет отдельные карточки с ценой, магазином, причиной, риском и статусом ссылки.
4. Для карточки можно выбрать ТОП-1, оставить/убрать её, поменять цену или ссылку, изменить порядок и открыть быстрый поиск по магазинам.
5. Полный отчёт не отправится, пока у ТОП-1 не подтверждены прямая ссылка и цена; остальные непроверенные карточки в отчёт не попадут.

## Ручная проверка карточек

- Ссылка из Алисы/GigaChat получает статус «🔍 ссылка найдена, но не проверена»; пустая ссылка — «⚠️ ссылка нужна».
- После ручной проверки нажмите «✅ Проверил ссылку». Неподходящую ссылку можно отдельно отметить.
- Актуальную цену подтвердите через «✏️ Изменить цену» — повторный ввод той же цены тоже засчитывается как проверка.
- Бот предупреждает о несовпадении магазина и домена ссылки, а для Авито напоминает проверить город, состояние товара, рейтинг продавца и подозрительно низкую цену.
- В финальный отчёт входят только оставленные карточки с подтверждённой ссылкой и ценой. ТОП-1 выше бюджета не выбирается и остаётся в блоке «Осторожно».

## Предпросмотры и выдача

- «👁 Полный предпросмотр для админа» показывает полную подборку только в админском чате и не меняет статус заявки.
- «👀 Клиентский предпросмотр до оплаты» отправляет короткий тизер: количество вариантов, ценность полного отчёта и цену услуги — без раскрытия товарных данных.
- «📩 Отправить полный отчёт» доступна после ручного подтверждения оплаты и содержит точные модели, цены, магазины, ссылки, риски и итоговый совет.

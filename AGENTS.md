# AGENTS.md

## Проект

`Найди выгоднее` — Telegram-бот подбора выгодных товаров. Сценарий: клиентский запрос -> заявка -> админ -> Gemini/Алиса -> карточки -> роли ТОП-1/запасной/бюджетный/осторожно -> предпросмотр -> оплата -> полный отчёт.

## Главная продуктовая цель

- Главный результат — точный товар дешевле сопоставимого рынка, который можно заказать на момент проверки.
- «Ниже рынка» разрешено писать только после сравнения той же модели, комплектации и состояния по нескольким независимым предложениям.
- Цена, прямая товарная ссылка, наличие и возможность заказа должны быть подтверждены непосредственно перед выдачей; абсолютную гарантию будущего остатка не обещать.
- Исключение для отдельного Avito Review по указанию владельца от 09.09.2026: проверка наличия и `stock` полностью отключена. Порядок отбора — описание и характеристики, полная цена и сравнение рынка, затем фотографии. Перед выдачей обновляются цена и активность страницы; это не подтверждение складского остатка. Не возвращать блокировку из-за отсутствующего, неопределённого или отрицательного `stock`.
- Новое указание владельца от 13.09.2026 отменяет добивку выдачи непроверенными объявлениями от 09.09.2026: Avito показывает клиенту только точные, безопасные, полностью проверенные предложения. В режиме «Найти выгоднее» обязательна подтверждённая экономия относительно сопоставимых предложений по правилам ниже; в «Найти точно» — проверенное совпадение. PS4 нельзя показывать по запросу PS5 даже с меткой отличия. 3/5 — максимум, не минимальная квота. Непроверенные, рискованные, неактивные и отличающиеся объявления остаются только в диагностике владельца. При отсутствии подходящих предложений — честный пустой результат, без подстановки.
- Уточнение владельца, зафиксированное 23.09.2026: при 3–9 других независимых сопоставимых продавцах разрешена карточка «Дешевле найденных аналогов» с размером выборки; «Ниже рынка» — от 10. Достаточна любая положительная разница полной цены с медианой: прежний порог 2 000 ₽ / 5% отменён для Avito. Это не отменяет совпадение характеристик, безопасность, проверку фото и обновление цены/активности страницы. Текущий поиск PS5 ограничен Ярославлем и самовывозом; города автоматически не расширять.
- Семейный запрос «PS5» без указанной версии допускает PS5 Slim и другие версии PS5, если они не нарушают явные ограничения. Указанная версия, память, дисковод и комплект обязательны. Рыночное сравнение всегда выполняется отдельно для конкретной версии и конфигурации; PS4 и аксессуары не являются совпадениями PS5.
- Дополнение владельца от 23.09.2026: отсутствие сведений о ремонте и оригинальности деталей допускается с явной видимой пометкой на карточке. Не объявлять неизвестную историю чистой и не смешивать её при сравнении с подтверждённой историей. Противоречия, дефекты, неизвестная полная цена, несовпадение запроса и незавершённая проверка фото/страницы по-прежнему блокируют рекомендацию.
- Уточнение владельца от 03.10.2026 для Avito: точное предложение с проверенными описанием, фото, полной ценой и активностью страницы можно показывать и при менее трёх сопоставимых продавцах — без ярлыка и суммы экономии. Отсутствие видимых противоречий на фото не подтверждает скрытую исправность; перед покупкой клиент проверяет товар у продавца. Распакованную консоль с указанным состоянием «Новое» не отмечать отдельно только из-за вскрытой упаковки. Прочие запреты на реальные противоречия и незавершённую проверку сохраняются. Это указание заменяет прежнее правило о пустом результате `bargain` без доказанной экономии.
- Если подтверждённой экономии нет, не выдумывать выгоду и не ослаблять проверки. Для Telegram допустим надёжный запасной вариант без ярлыка «ниже рынка».
- Для надёжного запасного варианта сначала проверять DNS, затем другие крупные магазины с понятными возвратом и гарантией. DNS не считать автоматически лучшим без проверки цены, наличия и условий.
- Количество заявок — средство проверки ядра. Качество, реальная выгода и возможность заказа важнее числа обработанных заявок.

## База знаний подбора

- При изменении подбора, промптов, вопросов клиенту и карточек использовать [docs/product_selection_knowledge.md](docs/product_selection_knowledge.md): проверенные источники, сопоставимость, полная цена, категории и понятные объяснения. Документ содержит внешние факты и явно обозначенные правила проекта; он не отменяет исключения Avito выше.
- Новую полезную информацию сохранять с датой и первичной ссылкой. Не считать сохранённые цены и условия вечно актуальными и не выдавать целевое правило за реализованное поведение.

## Запреты

- Не трогать `.env`, `.venv`, `bot.db`, `*.db`.
- Не менять Telegram token.
- Не менять `main.py` без прямого запроса.
- Не ломать SQLite-схему, оплату и кредиты.
- Не переписывать проект целиком.
- Не менять `app`-код, если задача про инструкции, агентов, промты или безопасные проверки.

## Роли отчёта

- `BEST` / `TOP` / `TOP1` = ТОП-1.
- `BACKUP` / `APPROVED_BACKUP` = запасной.
- `BUDGET` / `APPROVED_BUDGET` = бюджетный.
- `DO_NOT_BUY` / `CAUTION` = осторожно.
- `REJECTED` / `REJECTED_AUTO` не показывать клиенту. Исходные отклонённые Avito-объявления допустимы только в отдельной диагностике владельца; публичный `discoveredListings` пуст по указанию от 13.09.2026.

## Правила парсера

- URL не должен становиться отдельной карточкой.
- Любая правка парсера Gemini/Алисы требует теста в `tools/test_alice_parser.py`.

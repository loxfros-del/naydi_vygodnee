# pre-change-check

Перед правкой:

1. Выполнить `git status --short`.
2. Понять, какие файлы действительно нужны для задачи.
3. Не менять запрещённые файлы: `.env`, `.venv`, `bot.db`, `*.db`, `main.py`.
4. Не менять Telegram token, SQLite-схему, оплату/кредиты без прямого запроса.
5. Если есть чужие изменения, не откатывать их.
